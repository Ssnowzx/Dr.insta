## Gatilhos de compartilhamento

Sends/reach é o segundo sinal mais forte de ranqueamento. Uma pessoa compartilha
quando o post faz uma destas coisas:

| Gatilho | Aplica a este ICP? | Exemplo do que seria |
|---|---|---|

| **Tem utilidade prática** — "vou usar isso" | | |
| **Dá munição de argumento** — "eu falei" | | |
| **É status** — "compartilhar isso me posiciona" | | |
